Google Sheets 연결

브라우저 주소창의 일반 링크(.../spreadsheets/d/…/edit?gid=…)나 '파일 → 공유 → 웹에 게시'로 만든 CSV 링크를 그대로 붙여넣으면 자동으로 변환해서 불러옵니다. 단, 시트 공유 설정이 '링크가 있는 모든 사용자에게 공개(뷰어 이상)'로 되어 있어야 합니다 — "특정 사용자만" 설정이면 이 페이지(정적 파일)에서는 접근할 수 없어요. 시트 헤더는 계좌명, 자산군, 위험도, 구분, 종목명, 티커, 통화, 수량, 매입단가, 매입금액, 배율, 현재가, 거래량 순서를 권장합니다(헤더 이름만 맞으면 순서는 상관없어요). 현재가·거래량 칸에는 =GOOGLEFINANCE(티커,"price") / =GOOGLEFINANCE(티커,"volume") 수식을 넣어두면 시트가 알아서 값을 채워줍니다(종목을 새로 추가한 행에도 이 수식을 반드시 복사해 넣어야 값이 보입니다). 전일종가, 전일대비(%), 거래대금, 시가총액, 52주 최고, 최고대비(%), 52주 최저, PER, EPS 열도 헤더 이름만 똑같이 넣어두면 [관심종목] 탭에 자동으로 표시됩니다 — 없어도 되는 선택 항목이에요.

⚠️ 현재가·거래량이 비어 있거나 자꾸 옛날 값으로 보인다면 '웹에 게시(pub)'로 만든 링크를 쓰고 있을 가능성이 높습니다 — 이 방식은 구글이 몇 분~몇 시간 간격으로만 캐시를 갱신해서 실제 시트 값보다 느리게 반영돼요. 대신 시트에서 공유 → 링크 복사(주소가 .../edit?gid=... 형태)로 받은 일반 공유 링크를 붙여넣으면, 이 페이지가 매번 시트의 최신 값을 직접 읽어와서 훨씬 빠르게(새로고침 시 즉시) 반영됩니다.
